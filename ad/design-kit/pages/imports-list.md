# Imports

**Route:** /admissions/imports. **Role:** clerk/manager. **Primary action:** Upload enquiry list.

Header includes template download as a secondary link. Table columns: file, uploader/date, status, processed/total and result action. Running status shows real progress and last updated time.

Use “Needs review”, “Importing”, “Completed”, “Completed with errors” and “Failed”. Filename links to batch detail. No fake loading percentage. Empty state explains accepted formats and offers upload.

Test multiple batches, long filenames, resumed processing after refresh and mixed results. Staff must distinguish file validation from records already imported.
